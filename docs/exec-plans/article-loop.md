## Transformer trial

Use [the runbook](../../trials/transformer/RUNBOOK.md), or the memory-enabled B6–B9 path in
[the full trial](../../trials/transformer-memory/RUNBOOK.md). Prepare in the existing gitignored
iteration corpus; keep original materials read-only until authorized archive feedback.

1. `frame` commits reader, capability and scope; `develop-argument` builds the teaching order;
   `develop-examples` owns source coverage, evidence and code/math choices. Each skill can be
   rerun independently on the same brief.
2. Route factual lookups through evidence development, and genuine synthesis through
   `synthesis-research`. Confirm needed derivations such as scaling, positional encoding and
   normalization against the selected capability, rather than a mandatory five-section outline.
3. Draft, illustrate when useful and review with chapter criteria. The former missing opponent
   branch is fixed; inventing 正方 now fails the trial. Verify citations and copied local assets.
4. Run a cold author grill after ship review. It proposes learning work without editing the
   retrieval ledger. Package the chapter, verify all six required frontmatter fields and copy the
   folder to a temporary location to check portability. The author controls the destination move.
5. After actual delivery, record used-in and registry verdicts. Check intra-archive references
   before any confirmed rename. Material roles and source tiers stay with their existing owners.
